# Day2_NumPy

This project contains NumPy practice files for Day 2.

## Files

- `Day2_Revision.md` - Revision notes and interview questions.
- `array_creation.py` - Examples of creating arrays with NumPy.
- `reshape_arrays.py` - Shape manipulation examples.
- `broadcasting.py` - Broadcasting practice.
- `broadcasting_notes.md` - Notes on broadcasting.
- `random_numbers.py` - Random number generation examples.
- `boolean_filter.py` - Boolean indexing and filtering.
- `sorting.py` - Sorting and unique value examples.
- `student_performance.py` - Student performance analysis mini-project.
- `challenge_day2.py` - Coding challenge with random numbers.

## Usage

Run each Python file with:

```bash
python <filename>.py
```

Example:

```bash
python array_creation.py
```
