# CI/CD Metrics

Observability is important in automated delivery. The pipeline should capture and record:

- Build duration
- Test duration
- Deployment duration
- Deployment status
- Failure reason
- Application version

## Why it matters

Metrics make troubleshooting faster and help teams identify recurring issues in build, test, or deployment stages. They also help answer essential operational questions such as "which version is currently running" and "why did this release fail."
