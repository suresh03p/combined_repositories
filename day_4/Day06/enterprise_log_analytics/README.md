# Enterprise Log Analytics & Security Monitoring System

This package demonstrates an enterprise-style workflow for importing, validating, monitoring, analyzing, and archiving logs.

## Features
- Parse TXT, CSV, and JSON logs
- Validate timestamps, IP addresses, URLs, IDs, and error codes
- Detect suspicious activity such as repeated failed logins or invalid tokens
- Generate hourly, daily, error, user, and incident reports
- Archive logs and export data in JSON/pickle formats

## Run
```bash
python app.py
```
