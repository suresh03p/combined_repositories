# Day4_DataCleaning

This project contains a data cleaning workflow for an HR dataset.

## Files
- `Day4_Theory.md`: Theory notes on data cleaning.
- `employees_dirty.csv`: Dirty HR dataset used for cleaning.
- `dataset_inspection.py`: Inspect dataset structure and contents.
- `inspection_notes.md`: Notes from dataset inspection.
- `missing_values.py`: Demonstrate missing value detection and handling.
- `missing_value_report.md`: Report comparing missing value methods.
- `duplicates.py`: Detect and remove duplicate records.
- `datatype_conversion.py`: Convert columns to the correct data types.
- `data_transformation.py`: Rename, standardize, and add derived columns.
- `sorting_grouping.py`: Sort, filter, and group HR data.
- `eda_analysis.py`: Perform exploratory data analysis.
- `hr_data_pipeline.py`: End-to-end cleaning pipeline.
- `cleaned_hr_data.csv`: Output file from the pipeline.
- `department_summary.csv`: Department summary output.
- `data_quality_report.md`: Quality report from the pipeline.
- `EDA_Report.md`: Exploratory analysis findings.

## Usage
Run each script from the `Day4_DataCleaning` folder, for example:

```bash
python dataset_inspection.py
```
