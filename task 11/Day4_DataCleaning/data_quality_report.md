# Data Quality Report

- The dataset was loaded and inspected for missing values, duplicates, and incorrect data types.
- Duplicates were removed, and the dataset was reduced to unique records.
- Numeric columns were converted to the correct types, and missing values were imputed.
- `JoiningDate` was converted to datetime format.
- `AnnualSalary` was calculated for each employee.
- A department summary file was generated with average, maximum, minimum salary, and employee count.
