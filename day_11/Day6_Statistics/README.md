# Day 6 Statistics Learning Project

This project covers the main concepts of statistics for beginners using Python, NumPy, Pandas, and Matplotlib.

## Included Files
- `central_tendency.py` – Mean, Median, Mode and practice datasets
- `dispersion.py` – Range, Variance and Standard Deviation
- `percentiles.py` – Quartiles and percentiles
- `outlier_detection.py` – IQR-based outlier detection
- `z_score.py` – Z-score calculation and interpretation
- `probability.py` – Basic probability examples
- `correlation_statistics.py` – Covariance and correlation analysis
- `distribution.py` – Normal distribution and skewness exploration
- `student_statistics_project.py` – Full mini project using 100 students
- `Day6_Theory.md` – Basic statistical concepts explained in simple language
- `distribution_report.md` – Summary of distribution observations
- `Student_Statistical_Report.md` – Final report answering key questions

## How to Run
From the project folder:

```bash
python central_tendency.py
python dispersion.py
python percentiles.py
python outlier_detection.py
python z_score.py
python probability.py
python correlation_statistics.py
python distribution.py
python student_statistics_project.py
```

## Dataset Output
The student mini project creates:
- `data/students.csv`
- charts saved inside `charts/`

This project is designed to help understand:

- percentiles and quartiles
- outliers
- z-score
