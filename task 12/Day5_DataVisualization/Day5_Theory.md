# Day 5 Theory: Data Visualization

## What is Data Visualization?
Data visualization is the practice of converting data into visual forms such as charts, graphs, and maps. It makes complex data easier to understand by leveraging human visual perception.

## Why do we visualize data?
- To reveal patterns and trends quickly.
- To compare values across groups.
- To communicate analysis results clearly.
- To identify outliers, clusters, and anomalies.
- To support better decision-making.

## What is Matplotlib?
Matplotlib is a Python plotting library for creating static, interactive, and animated visualizations. It is the foundational library for plotting in Python and provides control over every element of a chart.

## What is Seaborn?
Seaborn is a Python library built on Matplotlib that provides a high-level interface for drawing attractive statistical graphics. It simplifies plotting with built-in themes and dataset-aware functions.

## Difference between Matplotlib and Seaborn
- Matplotlib is a general plotting library with detailed customization.
- Seaborn is designed for statistical plots and makes complex visualizations easier.
- Matplotlib uses lower-level plotting code.
- Seaborn adds default styling and works well with Pandas DataFrames.
- Seaborn is often faster to create polished charts with fewer lines of code.

## What is a chart?
A chart is a graphical representation of data that uses visual elements like lines, bars, points, and slices. Charts help viewers see relationships, distributions, and comparisons.

## What is an axis?
An axis is a reference line on a chart used to measure data values. Most charts have an x-axis (horizontal) and a y-axis (vertical).

## What is a legend?
A legend explains the symbols, colors, or patterns used in a chart. It maps chart elements to the data categories they represent.

## What is a title?
A title is text shown at the top of a chart that describes the purpose or main insight of the visualization.

## What is a label?
A label is text placed along an axis or a chart element that describes what the values represent.

## 20 Important Points
1. Visualizations convert numbers into visual patterns.
2. Good charts make it faster to interpret data.
3. Use line charts for trends over time.
4. Use bar charts for category comparisons.
5. Use scatter plots for relationships between variables.
6. Use histograms for distribution and frequency.
7. Use pie charts for parts of a whole.
8. Titles should be descriptive and concise.
9. Axis labels should describe units and metrics.
10. Legends are essential when multiple series appear.
11. Color choices affect readability.
12. Gridlines help estimate values accurately.
13. Data visualization is critical for storytelling.
14. Charts should avoid clutter and unnecessary decoration.
15. Matplotlib is the base library for Python plotting.
16. Seaborn is useful for statistical and thematic plots.
17. Seaborn works naturally with Pandas DataFrames.
18. Correlation heatmaps help identify variable relationships.
19. Box plots are useful for outlier detection.
20. EDA (exploratory data analysis) relies heavily on charts.
