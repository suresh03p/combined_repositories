# Supervised vs Unsupervised Learning

## Supervised Learning

Supervised learning is when the model learns from data where the correct answer is already known. The model sees input and output pairs and learns the relationship between them.

Examples:
- House features -> House price
- Student data -> Pass/Fail
- Customer data -> Churn/No Churn
- Email text -> Spam/Not Spam
- Medical data -> Disease/No Disease

## Unsupervised Learning

Unsupervised learning is when the data does not have known answers. The model tries to find hidden patterns, relationships, or groups in the data.

Example:
- Customer data -> Find groups
- Product data -> Discover similar products
- Website behavior -> Group visitors by activity
- Sensor data -> Detect unusual patterns
- Survey data -> Find hidden themes

## Regression

Regression predicts a continuous value.

Examples of regression:
1. Predicting house price from area and rooms
2. Forecasting temperature for tomorrow
3. Estimating product sales for next month
4. Predicting student marks from study hours
5. Forecasting company revenue

## Classification

Classification predicts a category or class.

Examples of classification:
1. Spam or not spam email
2. Dog or cat image recognition
3. Pass or fail based on marks
4. Fraud or genuine transaction
5. Customer churn or no churn

## Clustering

Clustering groups similar data points together without labels.

Examples of clustering:
1. Grouping customers by shopping behavior
2. Segmenting market customers by age and spending
3. Grouping documents by topic
4. Finding similar photos in a dataset
5. Grouping patients by symptoms

## Simple Difference

- Regression: predicts a number
- Classification: predicts a class
- Clustering: finds groups in unlabelled data
