# Day 7: Machine Learning Learning Path

This project contains a beginner-friendly machine learning workflow with theory notes and Python scripts.

## Project Files

- `Day7_Theory.md` - basic theory and glossary
- `ml_types.py` - supervised vs unsupervised learning examples
- `ml_types.md` - regression, classification, and clustering examples
- `sklearn_test.py` - checks scikit-learn installation
- `features_target.py` - features and target explanation
- `train_test_split.py` - train/test data split demonstration
- `student_score_model.py` - first linear regression model
- `linear_regression_math.py` - coefficient and intercept explanation
- `model_evaluation.py` - MAE, MSE, and R²
- `prediction_visualization.py` - chart of actual vs predicted values
- `house_price_prediction.py` - full mini project and model saving
- `ML_Workflow.md` - complete ML workflow explanation

## Run Example

```bash
python Day7_MachineLearning/sklearn_test.py
```

## Notes

The project uses Python, pandas, matplotlib, scikit-learn, and joblib.
