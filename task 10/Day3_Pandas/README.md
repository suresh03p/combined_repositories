# Day3_Pandas

This folder contains Python practice files for learning Pandas. It includes examples for Series, DataFrames, CSV operations, selection, filtering, employee analysis, and a student challenge.

Files:
- `Day3_Theory.md`
- `series_practice.py`
- `dataframe_practice.py`
- `csv_operations.py`
- `selection.py`
- `filtering.py`
- `employee_analysis.py`
- `challenge_day3.py`
- `employees.csv`
- `employee_report.csv`
- `screenshots/`

Usage:
1. Install Pandas: `pip install pandas`
2. Run practice scripts with Python.
