# Enterprise Log Processing Framework

## Features

- Lazy Log Reading Using Generators
- Memory Efficient Processing
- Multiple Log File Support
- Date Filtering
- Log Level Filtering
- Module Filtering
- Keyword Filtering
- Error Analysis
- Warning Analysis
- Average Response Time
- Success Rate Calculation
- Top Error Messages
- JSON Export
- CSV Export

## Run Application

```bash
python app.py
```

## Output Files

```text
reports/report.json
reports/report.csv
```
